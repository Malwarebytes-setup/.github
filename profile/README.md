## 🧠 Overview

Malwarebytes is an anti-malware and internet security utility that scans for and removes viruses, spyware, ransomware, and other malicious software. It provides real-time protection against threats that traditional antivirus programs may miss.

On a Windows machine it runs as a Windows utility with its own workspace, settings folder and uninstall entry. Typical use is security & antivirus work on local files, so the application does not need a subscription or a cloud project to open and save documents.
